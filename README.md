# 电子提单控制权交接

保证电子提单控制权、运输事实和跨境支付条件始终一致。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括进出口企业、承运人、贸易融资银行、提单平台运营方。

资料所依据的领域事实如下：

- 跨境服务平台联通电子提单平台
- 业务目标是统一信息流、资金流和单据流
- 贸易履约条件达到后才执行定向支付

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
